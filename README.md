# Xianyun Cheng: Academic Homepage

Source for **[shinecloud9.github.io](https://shinecloud9.github.io)**, the personal academic homepage of Xianyun Cheng
(MSc Mechanical Engineering, National University of Singapore).

The site covers:

- **Research**: LLM evaluation, format robustness and metamorphic testing of LLM document workflows
- **Publication**: *Not as Sweet by Another Name: An Empirical Study of Format Robustness in LLM Document Workflows* (ASE 2026)
- **Projects**: UV photodetector fabrication, an intelligent firefighting vehicle, a lightweight virtual try-on system, and more
- **Experience, education and awards**

It is a single self-contained `index.html` (no build step, no external dependencies), served by GitHub Pages.
